# COZY CAT PIXEL ART PACK

A cozy 2D pixel art cat pack for cozy games, farming sims,
RPGs, life sims, and other pixel-art projects.

This pack includes an animated 16x16 cat, separate props,
and ready-made cozy interaction scenes.

## WHAT'S INCLUDED

CAT — 16x16

Front View

* Idle
* Meow
* Staring

Front Sitting View

* Idle
* Meow
* Licking Paw

Side View

* Idle
* Walk

PROPS

* Cat Bed ............... 32x24
* Cardboard ............. 16x16
* Empty Bowl ............ 16x16
* Water Bowl ............ 16x16
* Food Bowl ............. 16x16
* Scratching Post ....... 16x24
* Yarn Ball ............. 12x12

EXTRAS / SCENES

* Sleeping Cat in Bed ... 32x24
  Animated breathing

* Playing With Yarn ...... 32x32
  Cat and yarn interaction

## FILE FORMATS

PNG
Spritesheets and individual/static assets.

JSON
Aseprite animation and frame data.

## FOLDER STRUCTURE

Front_View
Front-facing cat animations.

Side_View
Side-facing cat animations.

Props
Individual props without the cat.

Extras
Ready-made cat interaction scenes.

## PIXEL ART

All assets are provided at their original/native resolution.

For pixel-perfect scaling, use nearest-neighbor filtering
and integer scaling when enlarging the artwork.

## USAGE

The PNG assets can be used in any game engine or software
that supports PNG images.

The JSON files contain Aseprite animation data and are
intended for workflows that support Aseprite JSON data.
