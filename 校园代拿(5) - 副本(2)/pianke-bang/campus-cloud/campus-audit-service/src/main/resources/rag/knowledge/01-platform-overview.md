# 平台概览

标签：片刻帮 校园互助 跑腿 代拿 功能介绍 你是谁

片刻帮是校园互助跑腿平台，支持同学发布与接取校园代拿/跑腿任务。

主要功能：
- 任务大厅：浏览可接任务、筛选与搜索（游客可浏览，登录后才能发布/接单）
- 发布任务：填写取件/送达地点、酬劳说明，预付赏金后进入审核
- 接单配送：认证接单员可接单，与发布者私聊沟通
- 钱包：余额、流水、提现申请（仅认证接单员可提现）
- 优惠券与加急：发布时可抵扣优惠券、可选加急曝光
- 智能客服「片刻小新」与人工客服（转人工）
- 公告、系统通知、反馈申诉

角色：
- 普通用户：可发布任务、浏览大厅；未认证不能接单、不能提现
- 接单员：通过「接单员申请」审核后可接单与提现
- 管理员/人工客服：审核任务与申请、处理提现与客服会话
