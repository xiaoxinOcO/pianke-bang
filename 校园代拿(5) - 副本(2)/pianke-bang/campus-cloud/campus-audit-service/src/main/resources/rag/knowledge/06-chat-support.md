# 客服、私聊与反馈

标签：客服 片刻小新 转人工 私聊 聊天 反馈 申诉 投诉 头像

智能客服：
- 「片刻小新」解答平台使用类问题（发布、接单、钱包、认证、状态等）
- 可询问「我的钱包」「我的任务」等个人实时信息（需登录）
- 仅依据平台知识库与只读查询回答，不确定时会建议转人工

转人工：
- 在智能客服窗口点击「转人工」
- 人工客服在线时可接入；离线时请稍后再试或继续使用智能客服
- 资金纠纷、账号安全、违规封禁、复杂投诉建议转人工

私聊：
- 任务相关方可在聊天中沟通取件信息与进度
- 仅已认证接单员（及客服人员）可主动发起私聊
- 请勿在聊天中进行站外交易或泄露过多隐私

反馈与申诉：
- 可通过反馈入口提交问题；管理员可在后台查看处理
- 任务异常/驳回等可在个人中心或任务相关入口发起「申诉」（最多 800 字），系统会私信发送给管理员 admin
- 更细的申诉结果说明见「申诉与纠纷」文档

其他：
- 头像修改提交后需管理员审核通过才会生效
