# 如何发布任务

标签：发布 发单 下单 赏金 手续费 预付 审核 驳回 重新提交 支付 支付宝 优惠券

发布步骤：
1. 登录后进入「发布」入口，填写任务标题、取件地点、送达地点、酬劳金额与说明（可附图）
2. 提交后进入「待支付赏金」：用钱包余额或支付宝支付预付赏金（可选用优惠券抵扣）
3. 赏金支付成功后，任务进入「待管理员审核」
4. 审核通过后进入任务大厅，可被接单员接取
5. 若被驳回，可按提示修改后重新提交；驳回或取消时，已预付赏金会按规则退还到钱包

费用说明：
- 平台互助任务无额外「发布手续费」
- 发布时需预付赏金；赏金会先冻结，任务取消/驳回后退还
- 余额不足时可在钱包用支付宝充值后再支付（微信支付暂未开放）

注意：
- 赏金必须大于 0
- 未支付赏金的草稿约 1 小时后会自动取消；关闭支付窗也可能立即取消该草稿
- 描述请勿包含辱骂、色情等违规内容，否则审核可能驳回
- 当前配置下，支付赏金后仍需管理员审核通过才会上大厅（不会自动通过）
