校园代拿 · 云服务器部署清单（campus-cloud 微服务）

一、MySQL
  1. 安装并启动：sudo systemctl enable --now mysqld   （或 mysql）
  2. 建库：CREATE DATABASE campus_delivery CHARACTER SET utf8mb4;
  3. 账号密码与 campus-common/application-campus-shared.yml 一致，或用环境变量覆盖

二、中间件（Nacos / RabbitMQ / Elasticsearch）
  1. cd campus-cloud/deploy
  2. sudo docker compose up -d
  3. 自检：
     - Nacos 控制台 http://服务器IP:8848/nacos  （或按你映射的端口）
     - RabbitMQ 管理台 http://服务器IP:15672  guest/guest
  4. 生产环境请修改默认密码、关闭不必要的对外端口

三、编译并部署各微服务 jar
  1. 本机或服务器：cd campus-cloud && mvn -q -DskipTests package
  2. 将各模块 target/*.jar 拷到服务器 /opt/campus/services/
  3. /opt/campus/aliyun.env 填写短信密钥（见 aliyun.env.example）
  4. Linux 可用：chmod +x start-services.sh && ./start-services.sh start
     或为各 jar 分别建 systemd 单元（网关示例见 campus-gateway.service.example）
  5. 启动顺序：auth → user/wallet/audit/chat → task → gateway
  6. 自检：curl -sS -m 5 http://127.0.0.1:8080/api/tasks
     应很快返回 JSON，而不是卡住或 Connection refused

四、Nginx（关键：必须有 /api 与 /ws 反代）
  1. sudo cp nginx-campus.conf /etc/nginx/conf.d/campus.conf
  2. 按需改 root、server_name；微信小程序须配置 HTTPS（443 + 证书）
  3. sudo nginx -t && sudo systemctl reload nginx
  4. 浏览器 F12 里 /api/ 不能 404/504；聊天须能连 wss://域名/ws

五、前端
  1. 本机：cd frontend && npm run build（生产 VITE_API_ORIGIN 留空，走同源 /api）
  2. 将 dist/* 拷到 Nginx 的 root 目录
  3. cs-console、rider-console 同理 build 后部署（可子路径或子域名）

六、仍 504 / 注册一直提交中
  - 确认 campus-gateway 与六个业务服务均已注册到 Nacos
  - journalctl -u campus-gateway -n 80  （若用 systemd）
  - 安全组放行 80/443；8080/8101-8106 建议仅内网，由 Nginx 反代 8080

七、钱包扣款（小程序发布任务报「余额不足」但钱包页有余额）
  1. 确认 /opt/campus/application-prod.yml 含：
       campus:
         remote:
           wallet: true
  2. 重启 task-service 与 wallet-service（或 ./start-services.sh stop && start）
  3. 小程序重新发布任务验证

八、本地联调
  见上级目录 联调说明.txt、本目录 联调说明-微服务.txt
  本机没有 start-all.bat / start-all-microservices.bat；后端用 IDE 或 scripts\restart-all.ps1
