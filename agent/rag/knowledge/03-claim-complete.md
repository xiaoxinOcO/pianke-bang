# 如何接单与完成任务

标签：接单 配送 完成 确认 取消 任务大厅 私聊 自动确认 退回大厅

接单前提：
- 需先通过「接单员申请」成为认证接单员
- 信誉分需达到 60 分及以上；过低或被限制接单时，页面会提示禁止至何时

接单流程：
1. 在任务大厅浏览状态为「待接单」的任务
2. 可先与发布者私聊确认细节（仅认证接单员可主动发起私聊）
3. 确认路线与酬劳后点击接单，任务变为「配送中」
4. 配送过程中可与发布者保持沟通
5. 完成后提交完成说明/凭证，任务进入「待发布方确认」
6. 发布者确认完成后，酬劳进入接单员钱包余额
7. 仅发布者可对接单员评分（1～5 星，支持 0.5 步进），不能重复评分

自动确认：
- 进入「待发布方确认」后，若发布者约 30 分钟仍未操作，系统会自动确认完成并结算酬劳

取消规则（分阶段）：
- 已完成任务不可取消
- 「待发布方确认」时：发布者不能单方取消，应「确认完成」；有争议请私聊或向管理员申诉
- 「配送中」或「待发布方确认」时：接单员取消会把任务退回大厅（重新变为待接单），一般不退还发布者已预付赏金
- 其他未完成阶段（如待接单、待审核等）：发布者或相关方可取消；已预付赏金会按规则退还到发布者钱包
- 系统不会因「取消」自动扣信誉分；接单超时才会扣分（见信誉分说明）
