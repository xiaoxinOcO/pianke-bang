# 毕业论文生成说明

本目录用 **Python + python-docx** 生成 Word 论文，**不修改** `校园代拿` 业务代码。

## 文件

| 文件 | 作用 |
|------|------|
| `build_thesis.py` | 主入口：组装封面、摘要、目录、第1–7章、参考文献、致谢 |
| `thesis_format.py` | 排版：页边距、字体、1.25倍行距、三线表、页眉页码 |
| `thesis_content.py` | 元信息、摘要、目录条目、参考文献 |
| `基于SpringCloud+Vue的校园便民跑腿平台的设计与实现.docx` | 生成结果 |

## 生成命令

在 `论文` 目录执行：

```bash
python build_thesis.py
```

依赖：`pip install python-docx`

## 格式说明

因 `新建 Microsoft Word 文档 (2).docx` 当前为 **空文件（0字节）**，脚本按广工商/同类本科常见规范排版：

- A4；上下 2.5cm，左约 2.5cm（含装订），右 2cm
- 正文小四宋体 / Times New Roman，1.25 倍行距，首行缩进约 2 字符
- 摘要/目录/致谢标题：小二黑体居中（“摘  要”等中间空格）
- 一级标题四号黑体；二级及以下小四宋体加粗
- 表格为三线表；页眉为论文题目；页脚居中页码
- 文中 `[n]` 引用已设为上标

若学院有正式模板，把模板放到本目录后告诉我，可再按模板微调脚本。
